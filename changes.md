# Trinqle: Changelog & Release Notes (v1.0.0)

This file tracks major implementation milestones and v1.0.0 release readiness across the codebase.

---

## v1.0.0 (Release Baseline)

### Phase 1: Core Functional & Data Integrity Fixes
- **Form Engine Gate Logic ([`src/core/formEngine.ts`](src/core/formEngine.ts)):** Added `isQuestionVisible` and `isPartReachable` so core parts inside gated or conditional sub-questions do not block submission when the parent gate is `false` or unanswered; blank core `yesno` parts start `undefined` in [`NightlyFormModal.tsx`](src/ui/form/NightlyFormModal.tsx), required missing indicators cover gates/sub-questions, and editing preserves original `createdAt` & `backfilled` flags.
- **Session Carousel & Time Range Empty State ([`NightlyFormModal.tsx`](src/ui/form/NightlyFormModal.tsx), [`TimeRangeWidget.tsx`](src/ui/widgets/TimeRangeWidget.tsx)):** Fixed repeating session horizontal carousel containment (`w-full flex-none min-w-0 snap-center overflow-hidden`), added scroll-synced pagination dots, and added explicit `"Tap to set time range"` / `"Not set"` state when `value === undefined`.
- **Chapter Bounds & Closed Write-Lock ([`src/core/chapters.ts`](src/core/chapters.ts), [`src/data/db.ts`](src/data/db.ts)):** Enforced `MIN_CHAPTER_DAYS = 20`, `MAX_CHAPTER_DAYS = 45`, `MIN_END_DAYS_FROM_TODAY = 3` in [`EndDateModal.tsx`](src/ui/components/EndDateModal.tsx) and [`ChapterDetailsModal.tsx`](src/ui/components/ChapterDetailsModal.tsx); added Dexie database hooks locking closed chapters against direct mutations (`runBypassingClosedGuard` reserved for imports/reset/seeding).
- **Archive & Theme Isolation ([`src/ui/screens/ArchiveScreen.tsx`](src/ui/screens/ArchiveScreen.tsx), [`src/themes/registry.ts`](src/themes/registry.ts)):** Routed Archive ZIP drops through [`ImportDialog.tsx`](src/ui/dialogs/ImportDialog.tsx) confirmation; prevented Archive Mode previewing from overwriting saved `localStorage` theme preference.
- **Limits, Dates, Offline Fonts, PWA Prompt & Mascot Pivots:** Added [`src/core/limits.ts`](src/core/limits.ts) length bounds + counters across UI/repos/validators; banned `.toISOString().slice(0, 10)` via [`src/test/noUtcDateSlice.test.ts`](src/test/noUtcDateSlice.test.ts); switched `VitePWA` to `registerType: 'prompt'` ([`vite.config.ts`](vite.config.ts)); bundled `@fontsource/*` fonts offline ([`src/main.tsx`](src/main.tsx)); fixed SVG `transform-box: fill-box` pivots ([`animator.ts`](src/characters/animator.ts)).

### Phase 2: Security & Push Hardening
- **Fail-Closed Push Secrets & Per-Device Auth ([`api/`](api/), [`src/core/notifications/`](src/core/notifications/), [`src/sw/sw.ts`](src/sw/sw.ts)):** Removed all fallback VAPID keys and hardcoded emails; added 32-byte per-device `manageToken` (`SHA-256` hash stored in KV, `timingSafeEqual` verification on `/api/prefs`, `/api/unsubscribe`, `/api/send` test); required `CRON_SECRET` fail-closed; validated endpoint hosts, key byte lengths, IANA timezones, whitelisted prefs, and 4 KB body caps; synced `chapterPlannedEndDate` for `chapter_ending` reminders; hardened [`api/kv.ts`](api/kv.ts) with `SHA-256` keys, `SMEMBERS`+`MGET` pipeline, atomic Lua `recordSent`, and `503` when KV is unset outside tests.
- **SVG XSS, CSP & ZIP Bomb Guards ([`src/characters/sanitizer.ts`](src/characters/sanitizer.ts), [`vercel.json`](vercel.json), [`src/core/zip.ts`](src/core/zip.ts), [`src/core/export.ts`](src/core/export.ts)):** Replaced regex SVG sanitizer with `DOMPurify` + fail-closed `DOMParser` validation and import/render re-sanitization; added CSP & security headers in `vercel.json`; added actual inflated byte/ratio zip-bomb guards and image magic-bytes checks inside single Dexie transactions.

### Phase 3: Backup, Snapshots & Data Health Check
- **Persistent Storage & Full Backup ([`src/core/fullBackup.ts`](src/core/fullBackup.ts), [`src/ui/App.tsx`](src/ui/App.tsx)):** Auto-requested `navigator.storage.persist()` on launch; displayed storage protection status/warnings in Profile; added verified **Full Backup ZIP** (`formatVersion: 2`, all 16 stores excluding sensitive tokens, dry-run validation before share, Replace/Merge restore).
- **Honest Backup Status, Safety Snapshots & Health Check ([`src/core/snapshots.ts`](src/core/snapshots.ts), [`src/core/healthCheck.ts`](src/core/healthCheck.ts)):** Fixed aborted native share handling so cancelled exports do not advance timestamps; added Home backup nudge & status; implemented separate `trinqle_snapshots_db` retaining last 5 automatic snapshots before Delete All, Import Replace, Chapter Close (defaulting to Full Backup), and Data Health repairs; built read-only **Data Health Check** & **Recovery** modals.

### Phase 4: Form-Driven Generator, Hygiene, E2E & v1.0.0 Docs
- **Form-Driven Demo Generator & Empty-Home Scope Demo ([`src/tools/demoData.ts`](src/tools/demoData.ts), [`src/content/analytic-form-pack.json`](src/content/analytic-form-pack.json)):** Built a dynamic form-driven seeded generator (with explicit alert when no form is configured, realistic latent signals vs null mode, cycles, frozen closed chapters with photos/reflections), added numeric-rich `analytic-form-pack.json`, added a single-click **"See the scope of the app using fresh demo data"** button on empty Home, and gated Profile developer tools via [`isDevToolsEnabled()`](src/core/devFlag.ts).
- **Hygiene, ESLint & Playwright Mobile E2E ([`eslint.config.js`](eslint.config.js), [`playwright.config.ts`](playwright.config.ts), [`e2e/app.spec.ts`](e2e/app.spec.ts), [`.github/workflows/ci.yml`](.github/workflows/ci.yml)):** Removed unused `CycleCard.tsx` and legacy `run_*.cjs`/`.js` scripts; configured ESLint (`0` errors); bumped package & header version to `1.0.0` / `v1.0.0`; added mobile `390x844` Playwright E2E suite in CI and synchronized all project documentation.
